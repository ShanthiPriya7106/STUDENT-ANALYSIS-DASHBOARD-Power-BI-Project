📊 **Student Analysis Dashboard**

📌 **Project Overview**
● Developed an interactive Power BI dashboard for student data analysis.
● Tracks attendance, academic performance, fee status, and scholarship eligibility.
● Provides insights to support data-driven decision-making.

🎯 **Objectives**

● Monitor student attendance and performance.
● Identify students with pending fees or backlogs.
● Analyze scholarship eligibility.
● Compare student metrics across branches.

📈 **Key Features**

● KPI Cards for important metrics.
● Attendance Analysis.
● CGPA Performance Tracking.
● Backlog Analysis.
● Fee Status Monitoring.
● Scholarship Eligibility Analysis.
● Interactive Filters and Slicers.

🛠️ **Tools & Technologies**

● Power BI
● DAX (Data Analysis Expressions)
● Data Modeling
● Data Visualization

📊 **Dashboard Insights**

● Students Above vs Below 75% Attendance.
● Branch-wise Student Distribution.
● Total and Pending Fee Analysis.
● Scholarship Eligibility Trends.

🚀 **Skills Demonstrated**

● Data Cleaning
● Data Transformation
● DAX Calculations
● Dashboard Design
● Business Intelligence Reporting

📁 **Dataset Fields**

● Student Name
● Roll Number
● Branch
● Attendance
● CGPA
● Backlogs
● College Fee
● Pending Fee
● Scholarship Eligibility

📌 **Conclusion**

This dashboard helps educational institutions monitor student performance and financial status effectively through interactive visualizations and actionable insights.
